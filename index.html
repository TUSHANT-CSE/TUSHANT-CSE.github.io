02 / THE PERSON BEHIND THE CODE

Still learning.
Always building.

I like the space between an idea and a working system.

From HTML labs to React dashboards and payment reconciliation, every project is a chance to understand a new layer. Right now, I'm studying data structures, algorithms and machine learning, while getting deeper into TypeScript and backend engineering.

My approach is simple: make it work, understand why it works, then make it better. Document the trade-offs. Test the edges. Don't call a prototype production-ready.
